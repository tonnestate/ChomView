# Third-Party Notices and Conceptual Prior Art

ChomView is independently written. This repository does not intentionally copy source code, prompts, skill text, test corpora, or protected documentation from the projects and publications listed below.

They are acknowledged because their public work informed the research boundary around ChomView. No affiliation or endorsement is claimed.

## SOAR

Relevant conceptual area: cognitive architectures, impasse-driven subgoaling, bounded problem decomposition.

Canonical publication: Laird, Newell, and Rosenbloom, *SOAR: An Architecture for General Intelligence* (1987).

## Self-Refine

Source: https://arxiv.org/abs/2303.17651

Relevant conceptual area: iterative self-feedback and refinement.

## Reflexion

Source: https://arxiv.org/abs/2303.11366

Relevant conceptual area: verbal reinforcement, reflective memory, iterative agent improvement.

## Devil's Advocate

Source: https://aclanthology.org/2024.findings-emnlp.53/

Relevant conceptual area: anticipatory reflection, failure anticipation, pre-action critique.

## Agent Rigor

Source: https://github.com/ccromp/agent-rigor

Relevant conceptual area: independent advisory review and separation of review from verification.

Repository license and attribution obligations must be verified from the canonical repository before any future code or text reuse.

## COTA — Comparison-Only Tiny Advisor

Source: https://arxiv.org/abs/2608.21027

Relevant conceptual area: low-cost non-binding runtime advice from an auxiliary model.

## A2A Protocol

Source: https://github.com/a2aproject/A2A

Relevant conceptual area: explicit message identity, task/context identity, agent-to-agent messaging concepts.

ChomView does not implement the A2A protocol and BROTLI/1 is an independent, much smaller local thought-packet protocol.

## Test-suite reduction and cost-aware verification

Relevant conceptual area: balancing verification cost against useful fault-detection coverage.

ChomView does not claim novelty for minimum-cost test selection.

Do not copy third-party prompts, source code, documentation, schemas, examples, test corpora, or other protected artifacts into ChomView without:

1. identifying the canonical source and applicable license;
2. verifying that the intended reuse is permitted;
3. preserving any required attribution or notices;
4. documenting the reuse in this file;
5. ensuring compatibility with ChomView's Apache-2.0 distribution.

When uncertain, use external work only as conceptual reference and write an independent implementation.
