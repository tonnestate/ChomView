# Raw artifacts omitted from the GitHub distribution

The full EVAL-001 execution package contained the 48 run workspaces and generated result bundles. Those raw artifacts are intentionally **not** committed in this compact repository distribution because they add a large number of files and make manual GitHub upload cumbersome.

The repository retains the original core reports, corpus, environment metadata, randomization record, and the later audit/reclassification. These are sufficient to document what EVAL-001 originally reported and why its confirmatory conclusion is no longer treated as reliable.

The full raw package should be archived externally if long-term forensic reproduction is required.
